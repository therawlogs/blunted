# blunted 1.0.0 release evidence

Release source: tag `v1.0.0`, commit `ccaa8aad43155f57d5cb8aaf61e92fc42d022f41`.
The CI-only follow-up `7ee1664` generates the frontend before Rust tests and
adds an explicit ref input. Both successful workflows checked out the unchanged
release tag; initial tag-triggered runs failed because their test step preceded
frontend generation. No source tag was moved.

- [Mac build](https://github.com/therawlogs/blunted/actions/runs/39636949787)
- [Windows build](https://github.com/therawlogs/blunted/actions/runs/39636955724)
- [Release downloads](https://github.com/therawlogs/blunted/releases/tag/v1.0.0)

58 JavaScript tests and five Rust filesystem tests passed. Local portable output
rebuilt byte-identically and matches both CI portable files. An optimized local
Mac app was produced and passed strict signature checks. The downloaded CI DMG
also passed checksum validation; its bundled app reports version 1.0.0 and passed
`codesign --verify --deep --strict`. Downloaded Windows files matched their CI
manifest; the ZIP contains the exact same installer bytes as the standalone EXE.
