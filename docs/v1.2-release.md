# blunted v1.2.0 — offline spelling and grammar

Date: 27 October 2026. Status: **release candidate prepared**. The owner requested
publication, upgrade of `/Applications/blunted.app`, and removal of duplicate app
bundles. Publication, installer provenance and the completed local upgrade must be
recorded from their actual outcomes; preparation is not proof of any of them.

## Changes

- Bundle Harper 3.0.0 and its dictionary for English spelling, grammar and
  punctuation checking, with no account, checking service or runtime download.
- Show Original/Proposed previews and spelling alternatives before individual
  Apply actions. Preserve native Undo, Markdown and exact ranges after emoji.
- Keep intentional words for the active article and offer American, British,
  Australian, Canadian and Indian English in Settings → Review.
- Add Structure heading-level corrections; keep paragraph/opening feedback as
  guidance rather than automatic rewrites.
- Group settings into Appearance, Review and Library, hide technical review
  thresholds under Advanced, and report settings-save failures separately.
- Require explicit Clear confirmation with Cancel as the initial action. Prevent
  closing after successful Clear from recreating removed preferences.

See [the workflow](article-workspace.md), [proofreading details](offline-proofreading.md),
and [third-party notices](../THIRD_PARTY_NOTICES.md).

## Compatibility and delivery

The existing bundle identifier and article-library format are retained. New
global preferences are `spelling` and `grammar` (both default true), and
`proofreadingDialect` (default `american`, with the five varieties above). They
use the existing preference sanitizer, settings transfer and optional library
backup preference restore. Article voice words remain article-scoped.

Harper requires WebAssembly and Web Workers. Its pinned engine and dictionary
are embedded in both portable HTML and the desktop frontend; the portable file
is approximately 27.7 MB. Builds use pinned esbuild 0.25.12. The readability
engine's independent version remains separate from the Harper version.

Planned distribution matches v1.1.0: Apple-Silicon Mac DMG, Windows x64 NSIS
installer and ZIP, portable `index.html`, and `SHA256SUMS.txt`. The Windows
installer configuration embeds the offline WebView2 installer. Mac packages are
ad-hoc signed and not notarized; Windows packages are unsigned.
