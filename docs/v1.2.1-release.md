# blunted v1.2.1

Date: 31 October 2026. Status: **published stable/latest; Applications installed; post-upgrade UI verification pending Mac unlock**.

## Changes

- Genuine native whole-interface zoom (50–200%), View → Zoom to 200%, Actual Size and Cmd/Ctrl+0. Font preferences stay separate.
- Placeholder contrast of 5.49:1 light / 7.62:1 dark.
- One accessible Settings modal for Clear, named warning, exposed native Cancel/destructive controls, visible default Cancel focus, safe cancellation and result focus.
- Autosave/storage recovery: clear stale article/preference error notices after their corresponding successful save without clearing unrelated notices. Real native save failures now expose the underlying reason in the recovery strip.

## Autosave investigation boundary

The owner reported a saving/storage error. At investigation time, Autosave was enabled, Private Session was off and the real selected library was writable. The installed v1.2.0 app autosaved a synthetic article to its exact on-disk body without manual Save. The owner's original failing storage operation was not reproduced in the live library.

Two reproducible defects were found: article and preference error notices remained visible after successful storage recovery. Regression tests fail before the fix and pass after it. The release repairs these stale warnings and surfaces actual native error details; it does not claim that permission denial, a full disk or a disconnected folder is now writable. Existing recovery/export/retry behavior remains.

[Red reproduction](evidence/v1.2.1/autosave-red.txt), [green verification](evidence/v1.2.1/autosave-green.txt). Further user-provided error details should be investigated against the exact message rather than assumed resolved.
